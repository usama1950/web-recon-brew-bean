# Brew & Bean Cafe – Cyber Security Assessment

## Project Overview

This project presents a basic cybersecurity assessment and awareness campaign for Brew & Bean Cafe. It combines Linux security exercises, web reconnaissance findings, security recommendations, and phishing awareness guidance.

## Key Findings

- Practiced SSH remote access and Linux file handling.
- Identified six distinct URLs during web reconnaissance.
- Identified the `category` parameter for further security testing.
- Documented SQL injection as a potential concern, not a confirmed vulnerability.

## Security Recommendations

1. Enforce strong and unique passwords.
2. Regularly update web applications and validate user input.
3. Enable Multi-Factor Authentication (MFA).
